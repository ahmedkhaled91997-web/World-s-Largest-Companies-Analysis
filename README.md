# 📊 لوحة تحكم الأداء المالي وإنتاجية رأس المال البشري | Corporate Analytics Dashboard

لوحة تحكم تفاعلية متكاملة لتحليل البيانات المؤسسية، تم تطويرها باستخدام لغة **Python** وإطارات العمل **Streamlit** و **Plotly**. يهدف هذا المشروع إلى تقديم رؤى استراتيجية تدعم اتخاذ القرار، عبر تحليل كفاءة تحويل الإيرادات، قياس إنتاجية العمالة، وتحديد الانحرافات الإحصائية والقيم الشاذة (Outliers) عبر مختلف القطاعات الاقتصادية والأسواق الجغرافية.

---

## 🎯 متطلبات المشروع المنجزة (Requirements Fulfilled)
تمت هندسة وبناء لوحة التحكم لتلبية كافة المعايير والضوابط الفنية لتحليل البيانات:
*   **تطهير البيانات وتنقيتها (Data Cleansing):** يعتمد النموذج على قاعدة بيانات مصححة إحصائياً بعد عزل القيم الشاذة باستخدام منهجية المدى الربيعي (1.5x IQR).
*   **مؤشرات الأداء الرئيسية (KPI Cards):** توفير رؤية فورية شاملة لأعلى الهيكل المالي تشمل: **إجمالي الإيرادات**، **إجمالي صافي الأرباح**، و**متوسط هامش الربح**.
*   **أدوات تصفية ديناميكية (Dynamic Filters):** تضمين فلاتر تفاعلية متعددة (**حسب القطاع التشغيلي Industry** و**حسب الدولة الجغرافية Country**) تمكن المستخدم من فرز وتحليل البيانات لحظياً.
*   **رسومات بيانية متقدمة (Visualizations):** دمج مخططات تفاعلية عالية المنفعة (مخطط مبعثر لوغاريتمي Scatter Plot، مخطط دائري مجوف للحصص السوقية Donut Chart، ومخططات صندوقية Box Plots).

---

## 🚀 الرؤى الاستراتيجية المستخرجة (Business Insights)
1.  **إنتاجية العمالة (Labor Productivity):** دراسة وتحليل كفاءة العائد لكل موظف مقارنة بحجم نمو المبيعات، وتحديد مستويات وفورات الحجم (Economies of Scale) عبر القطاعات.
2.  **كفاءة تحويل الأرباح (Conversion Efficiency):** قياس الفجوة التشغيلية بين تدفقات الإيرادات الخام وصافي الأرباح المحتجزة، لعزل العمليات ذات الكثافة البيعية منخفضة الهامش عن قنوات الكفاءة المرتفعة.
3.  **تحديد الانحرافات التشغيلية (Outlier Tracking):** رصد وتوثيق الحالات الاستثنائية بالاسم من عمود `name` (مثل الكفاءة السعرية لـ *Nvidia* وإنتاجية رأس المال البشري لـ *Saudi Aramco*) وتحليل أسباب خروجها عن النطاق الإحصائي لأقرانها.

## 🛠️ البيئة البرمجية وحزمة التقنيات (Tech Stack)
*   **لغة البرمجة الأساسية:** Python 3.x
*   **إطار عمل الواجهة:** Streamlit (لتطوير ونشر لوحات التحكم التفاعلية).
*   **مكتبة الرسوم التوضيحية:** Plotly Express (لإنشاء مخططات بيانية ديناميكية متجاوبة).
*   **إدارة وهندسة البيانات:** Pandas & NumPy (للتجميع الإحصائي والتصفية الحسابية).

## 📦 إرشادات التثبيت والتشغيل المحلي (Installation & Setup)

لتشغيل لوحة التحكم التفاعلية محلياً على بيئتك البرمجية، يرجى اتباع الخطوات التالية:

### 1. هيكلة مجلد المشروع
يرجى التأكد من مطابقة البنية الشجرية للملفات داخل المجلد الرئيسي:
```text
📂 Your-Project-Folder/
├── 📄 dashboard.py           # الكود البرمجي الأساسي للوحة التحكم Streamlit
├── 📄 data.csv               # قاعدة البيانات المطهرة والمصححة
└── 📄 README.md              # وثيقة الشرح الفني (هذا الملف)
```

### 2. تثبيت الحزم والمكتبات الاعتمادية
افتح واجهة السطر البرمجي (Terminal / Command Prompt) في مسار المشروع، ثم نفّذ الأمر التالي:
```bash
pip install streamlit plotly pandas numpy
```

### 3. تشغيل منصة العرض (Launch)
قم بتشغيل تطبيق Streamlit عبر سطر الأوامر باستخدام الأمر التالي:
```bash
streamlit run dashboard.py
```
*(ملاحظة فنية: يرجى تجنب تشغيل الملف عبر خيار التشغيل الافتراضي "Run" داخل محررات الأكواد لضمان عمل خادم الويب المحلي، حيث يقوم الأمر أعلاه بفتح اللوحة تلقائياً في المتصفح).*

## 🖥️ دليل استخدام لوحة التحكم (User Guide)
*   **لوحة التحكم الجانبية (Sidebar):** تتيح القوائم المنسدلة تخصيص العرض لقطاع محدد أو سوق جغرافي معين، وتحديث المؤشرات والرسوم فوراً. اختيار "All" يعيد ضبط النموذج لعرض البيانات الإجمالية.
*   **استكشاف البيانات التفاعلية (Hover Feature):** يتيح تمرير الفأرة فوق أي نقطة بيانات قراءة التفاصيل الدقيقة للشركة (الاسم، حجم الإيرادات، صافي الأرباح، والدولة الحاضنة) عبر النوافذ المنبثقة.
